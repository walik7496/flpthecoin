# Yes or No? Coin Flip

A lightweight, single-page web app that uses an animated coin flip to help you choose between **Yes** and **No**.

## Features

- Randomly selects **Yes** or **No** with a 50/50 chance.
- Shows a coin-flip animation before displaying the result.
- Disables the button while the animation is running.
- Works in modern browsers without installation or external dependencies.
- Built with plain HTML, CSS, and JavaScript.

## How It Works

When the button is clicked, the app randomly chooses Yes or No, plays a CSS animation, and displays the result.

The random choice uses JavaScript's Math.random(). It is intended for casual decisions and is not suitable for security-sensitive or cryptographic use.
